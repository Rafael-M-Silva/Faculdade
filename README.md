# Faculdade — portfólio acadêmico inicial

Registro de um portfólio criado durante os primeiros estudos de desenvolvimento web. As páginas apresentam Rafael, o contexto de aprendizagem da época e projetos destacados naquele momento.

**Projeto desenvolvido para fins educacionais.** O texto do site representa uma fase anterior da trajetória profissional; para a apresentação atual, consulte o [perfil principal](https://github.com/Rafael-M-Silva).

## Conteúdo

- <code>index.html</code>: apresentação e projeto em destaque.
- <code>about.html</code>: página sobre o autor.
- <code>projects.html</code>: lista de projetos.
- <code>img/</code>: imagens usadas nas páginas.

## Como abrir

~~~bash
git clone https://github.com/Rafael-M-Silva/Faculdade.git
cd Faculdade
~~~

Abra <code>index.html</code> no navegador. Não há instalação de dependências.

## Estado do acervo

As páginas referenciam arquivos em <code>css/</code>, mas essa pasta não está presente no branch padrão auditado. A apresentação visual pode, portanto, estar incompleta. Alguns links e textos de contato são antigos e devem ser conferidos antes de reutilizar o site como portfólio atual.

## Aprendizados

O repositório preserva a prática inicial de páginas HTML, navegação e apresentação de projetos. Mantê-lo como acervo histórico ajuda a mostrar evolução sem confundi-lo com o portfólio atual.
